# buddhist-game-pixel-art

**佛教题材游戏美术素材 · 像素风**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一套为佛教寺院经营题材游戏准备的像素美术素材，共 1080 个文件（778 张 PNG、296 个 GIF、5 个 Python 脚本）。

素材按用途分三类：可玩的场景与人物（名刹 / 奇观 / 圣迹副本图、人物立绘）、可动画的角色（npc_sprites、角色立绘）、可拼装的建筑（建筑）。场景图取景自真实寺院、石窟与佛塔，文件名即原型。

## 目录结构

| 目录 | 内容 | 数量 | 规格 |
| --- | --- | --- | --- |
| `奇观副本图/` | 佛教奇观场景，如云冈石窟、乐山大佛、阿旃陀石窟 | 62 PNG | 1024×576，P 模式 |
| `名刹副本图/` | 名刹场景，如般若寺、表训寺、慈恩寺、法源寺、法云庵 | 34 PNG | 1024×576，P 模式 |
| `圣迹副本图/` | 圣迹场景，如白马寺、法门寺、峨眉山（普贤菩萨道场）、大悲禅院 | 29 PNG | 1024×576，P 模式 |
| `人物立绘/` | NPC 半身立绘，按编号命名 | 73 PNG | 256×384，RGBA |
| `npc_sprites/` | 74 个职位的行走动画，每个目录 `back/front/left/right` 四向 GIF 加一张 `walk.png` | 296 GIF + 74 PNG | GIF 64×64 |
| `角色立绘/` | 74 个职位的四向站立图，每目录 4 张 | 296 PNG | 32×119，RGBA |
| `建筑/成品/` | 已抠图、可直接使用的建筑 | 65 PNG | 2730×1536，RGBA |
| `建筑/需要加工/` | 已换色、待抠图的建筑 | 65 PNG | 2730×1536，RGBA |
| `建筑/需要先换色/` | 原始配色、待处理的建筑 | 31 PNG | 2730×1536，RGBA |
| `建筑/背景/` | 寺院的东南西北中五方背景 | 5 PNG | 2730×1536，RGB |
| `游戏副本/图鉴翻牌 4/` | 图鉴翻牌小游戏素材：东大寺 16 张（`原版像素` 与 `50K以内` 两档），华严寺彩塑像素化、国清寺、求礼华严寺各 8 张 | 40 PNG | 384×512，P 模式 |
| `游戏副本/禅宗拼图 4/` | 拼图小游戏素材 | 4 PNG | 1024×576，P 模式 |

`npc_sprites/` 与 `角色立绘/` 下的 74 个职位目录采用同一套编号与命名（01_上座（寺主）、02_维那、03_库头……74_磨头），按编号即可把动画、立绘与人物立绘对应起来。

## 脚本

`建筑/` 下 5 个 Python 脚本是素材流水线，依赖 `Pillow` 与 `numpy`：

| 脚本 | 作用 |
| --- | --- |
| `batch_color_grade.py` | 批量降饱和调色，`需要先换色` → `需要加工` |
| `batch_cutout.py` | 按近白像素（RGB 均 > 235）从四角 BFS 连通抠白底，`需要加工` → `成品` |
| `batch_cutout_fix.py` | 采样四角实际背景色作为基准的抠图修正版，`需要加工` → `成品` |
| `cut_rail_gaps.py` | 修掉 义冢、药园、码头 三张成品图上的围栏缺口 |
| `cut_special_stalls.py` | 抠出 庙市、施粥棚、素斋摊 三个摊位的背景 |

注意：脚本内的输入输出路径是写死的绝对路径（`D:\做个游戏\美术参考\...`），换机器或换目录后需要先改掉这几行才能跑。

## 说明

- 场景图、建筑图均为像素化再创作，不是对实物的写实还原；原型寺院、石窟、佛塔的名称仅用于标注题材来源。
- `建筑/成品/` 里的图为 2730×1536 的高分辨率像素图，缩放到游戏内尺寸时请用最近邻采样（nearest neighbor），否则像素颗粒会被插值糊掉。
- 本仓库不含引擎工程与游戏逻辑代码，只有美术素材和素材处理脚本。
